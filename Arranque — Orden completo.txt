Arranque — Orden completo
Paso 1 — Base de datos
Abre XAMPP Control Panel → en la fila MySQL pulsa Start → espera a que diga Stop.

Verificación: http://localhost/phpmyadmin → deben aparecer medicamentos_db, ventas_db, reportes_db.

Paso 2 — medicamentos-service
Terminal 1 en VS Code (Ctrl + ñ o menú Terminal → Nueva terminal):

text
cd "C:\Users\aleja\OneDrive\Escritorio\ADSO\5\Angarita\22-09-2026\MultiServicioDrogueria"
cd medicamentos-service
npm start
Debe aparecer:

text
Medicamentos Service corriendo en http://localhost:3001
No cierres esta terminal.

Probar:

text
http://localhost:3001/api/v1/medicamentos?page=1&limit=10

json
{"data":[],"totalRecords":0,"currentPage":1,"totalPages":0}
